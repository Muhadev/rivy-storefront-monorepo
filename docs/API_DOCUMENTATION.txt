## Overview

Welcome to the Rivy Clean Energy Storefront API documentation. This RESTful API powers a modern e-commerce platform specializing in sustainable energy solutions including solar panels, batteries, inverters, and wind turbines.

### Key Features
- **Secure Authentication**: JWT-based authentication with role-based access control
- **Product Catalog**: Comprehensive product management with categories and search
- **Shopping Cart**: Persistent cart functionality for authenticated users
- **Order Management**: Complete order lifecycle from creation to fulfillment
- **Review System**: Customer reviews and ratings for products
- **Discount System**: Flexible discount codes and promotional pricing

### Technology Stack
- **Runtime**: Node.js with Express.js
- **Database**: PostgreSQL with Sequelize ORM
- **Authentication**: JWT tokens with bcrypt password hashing
- **Validation**: Zod schema validation
- **Security**: Helmet, CORS, rate limiting, and security headers

## Authentication & Authorization

### Authentication Flow

The API uses JWT (JSON Web Tokens) for authentication. Here's how it works:

1. **Registration/Login**: User provides credentials and receives a JWT token
2. **Token Usage**: Include the token in the `Authorization` header for protected routes
3. **Token Format**: `Authorization: Bearer <your-jwt-token>`

### User Roles

- **Customer** (`customer`): Can browse products, manage cart, place orders, write reviews
- **Admin** (`admin`): All customer permissions plus product management, order management, user management

### Protected Routes

Most cart, order, and user management endpoints require authentication. Product browsing is public.

## Error Handling

### HTTP Status Codes

- **200**: Success
- **201**: Created successfully
- **204**: Success with no content
- **400**: Bad request (validation errors, missing required fields)
- **401**: Unauthorized (invalid or missing token)
- **403**: Forbidden (insufficient permissions)
- **404**: Resource not found
- **409**: Conflict (duplicate email, insufficient stock)
- **429**: Too many requests (rate limit exceeded)
- **500**: Internal server error

### Common Error Scenarios

**Validation Error (400)**
```json
{
  "error": {
    "message": "Validation failed",
    "code": "VALIDATION_ERROR",
    "details": {
      "email": "Invalid email format",
      "password": "Password must be at least 8 characters"
    }
  }
}
```

**Authentication Error (401)**
```json
{
  "error": {
    "message": "Invalid or expired token",
    "code": "UNAUTHORIZED"
  }
}
```

**Resource Not Found (404)**
```json
{
  "error": {
    "message": "Product not found",
    "code": "PRODUCT_NOT_FOUND"
  }
}
```

### Authentication

#### POST `/auth/register`
**Purpose**: Create a new user account  
**Authentication**: None required

**Request Body**:
```json
{
  "email": "customer@example.com",
  "password": "securePassword123",
  "name": "John Doe",
  "role": "customer"  // optional, defaults to "customer"
}
```

**Validation Rules**:
- `email`: Must be valid email format, unique in system
- `password`: Minimum 8 characters
- `name`: Minimum 2 characters
- `role`: Either "customer" or "admin" (admin registration may be restricted)

**Success Response (201)**:
```json
{
  "data": {
    "user": {
      "id": 1,
      "email": "customer@example.com",
      "name": "John Doe",

}
```

## Frontend Integration Guide

### Setting Up API Client

**Base Configuration**:
```javascript
const API_BASE_URL = 'http://localhost:4000/api/v1';

// Create axios instance with base configuration
const apiClient = axios.create({
  baseURL: API_BASE_URL,
  timeout: 30000,
  headers: {
    'Content-Type': 'application/json',
  },
});

// Add authentication interceptor
apiClient.interceptors.request.use((config) => {
  const token = localStorage.getItem('authToken');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});
```

### Error Handling
```javascript
apiClient.interceptors.response.use(
  (response) => response,
  (error) => {
    const errorMessage = error.response?.data?.error?.message || 'An error occurred';
    
    // Handle different error types
    switch (error.response?.status) {
      case 401:
        // Redirect to login
        localStorage.removeItem('authToken');
        window.location.href = '/login';
        break;
      case 429:
        // Rate limit exceeded
        showNotification('Too many requests. Please try again later.', 'warning');
        break;
      default:
        showNotification(errorMessage, 'error');
    }
    
    return Promise.reject(error);
  }
);
```

### Authentication Flow
```javascript
// Login
async function login(email, password) {
  try {
    const response = await apiClient.post('/auth/login', { email, password });
    const { token, user } = response.data.data;
    
    localStorage.setItem('authToken', token);
    localStorage.setItem('user', JSON.stringify(user));
    
    return { user, token };
  } catch (error) {
    throw new Error(error.response?.data?.error?.message || 'Login failed');
  }
}

// Logout
function logout() {
  localStorage.removeItem('authToken');
  localStorage.removeItem('user');
  window.location.href = '/login';
}
```

### Product Fetching with Pagination
```javascript
async function fetchProducts(filters = {}) {
  try {
    const params = new URLSearchParams();
    
    // Add filters to query params
    Object.entries(filters).forEach(([key, value]) => {
      if (value !== undefined && value !== null && value !== '') {
        params.append(key, value.toString());
      }
    });
    
    const response = await apiClient.get(`/products?${params}`);
    return response.data;
  } catch (error) {
    throw new Error('Failed to fetch products');
  }
}
```

## Rate Limiting & Performance

### Rate Limits
- **Authentication endpoints**: 5 requests per minute per IP
- **General API endpoints**: 100 requests per minute per IP
- **Cart operations**: 20 requests per minute per authenticated user

### Caching Recommendations
- **Product catalog**: Cache for 5 minutes
- **Categories**: Cache for 30 minutes
- **User cart**: No caching (real-time data)
- **Order history**: Cache for 1 minute

### Performance Tips
1. **Pagination**: Always use pagination for list endpoints
2. **Selective fields**: Request only needed data
3. **Batch operations**: Prefer batch operations when available
4. **Connection pooling**: Reuse HTTP connections
5. **Error handling**: Implement exponential backoff for retries

## Security Considerations

### Authentication Security
- JWT tokens expire after 24 hours
- Implement token refresh mechanism
- Store tokens securely (not in localStorage for production)
- Validate all user inputs on frontend before sending

### Data Protection
- Never log sensitive data (passwords, tokens)
- Validate file uploads if implementing image upload
- Sanitize all user inputs to prevent XSS
- Use HTTPS in production

### API Security
- CORS is configured for frontend domain
- Rate limiting prevents abuse
- All admin endpoints require proper authorization
- SQL injection protection via Sequelize ORM

## Support & Troubleshooting

### Common Issues

**Authentication Errors**:
- Verify JWT token format and expiry
- Check Authorization header format: `Bearer <token>`
- Ensure user has required permissions for admin endpoints

**Product Fetching Issues**:
- Verify query parameter formats
- Check pagination limits (max 100 items per page)
- Validate category IDs exist

**Cart Problems**:
- Ensure user is authenticated
- Check product stock availability
- Verify product IDs are valid

**Order Issues**:
- Ensure cart is not empty before checkout
- Validate shipping address format
- Check for sufficient product stock

Each response includes a `correlationId` for request tracking. Include this ID when reporting issues.
